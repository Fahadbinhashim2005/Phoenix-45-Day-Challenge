# 📝 Smart Notes Pro

A modern note-taking web application built as part of **Project Phoenix Day 6**.

## 🚀 Overview

Smart Notes Pro helps users organize ideas, study notes, project plans, and personal thoughts in one place.

This project is being developed as part of the **µLearn #cl-web-smartnotes challenge** while following the Project Phoenix learning philosophy:

> "If I don't understand it, I don't paste it."

---

## ✨ Features Completed (Day 6)

### UI Foundation

* Responsive sidebar layout
* Modern Phoenix-themed design
* Search bar section
* Sorting section
* Theme toggle button (UI only)
* Add Note button (UI only)

### Dynamic Notes System

* Notes stored in a JavaScript array
* Dynamic rendering using:

  * createElement()
  * appendChild()
  * forEach()
* Notes generated completely through JavaScript
* No hardcoded note cards

### Notes Card Design

* Modern card layout
* Hover effects
* Category labels
* Responsive notes grid

### JavaScript Concepts Learned

* DOM Selection
* Dynamic Element Creation
* DOM Rendering
* Arrays & Objects
* forEach()
* classList
* appendChild()
